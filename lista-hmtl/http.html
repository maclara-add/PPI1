    • O Protocolo HTTP na Prática

    Comunicação entre Navegador e Servidor

    O HTTP (Hypertext Transfer Protocol) é o protocolo responsável por permitir a comunicação de dados na World Wide Web. O navegador atua como o cliente que inicia solicitações, e o sistema remoto atua como o servidor que processa o pedido e retorna os dados necessários.

    Conceitos: Cliente, Servidor, Requisição e Resposta

    • Cliente: O software (geralmente um navegador) que faz a solicitação de um recurso.
    • Servidor: O computador/sistema central que armazena os arquivos da aplicação e responde às solicitações.
    • Requisição (Request): A mensagem enviada pelo cliente pedindo um recurso específico.
    • Resposta (Response): A resposta retornada pelo servidor contendo os dados solicitados ou informações sobre o status do processamento.

    Métodos HTTP: GET e POST

    GET: Utilizado para solicitar e buscar dados de um recurso específico sem alterar o estado do servidor. Os parâmetros são transmitidos na própria URL.

    POST: Utilizado para enviar dados ao servidor para criar ou atualizar um recurso (ex: envio de formulários). Os dados são transmitidos no corpo da requisição.

    Exemplo de Requisição HTTP

    GET /index.html HTTP/1.1
Host: www.exemplo.com.br
User-Agent: Mozilla/5.0
Accept: text/html

    Exemplo de Resposta HTTP

    HTTP/1.1 200 OK
Date: Wed, 20 Mar 2026 12:00:00 GMT
Content-Type: text/html; charset=UTF-8
Content-Length: 1256

<!DOCTYPE html>
<html>...</html>

    Códigos de Status HTTP

    • 200 OK: A requisição foi bem-sucedida e o recurso foi retornado.
    • 301 Moved Permanently: O recurso solicitado foi movido permanentemente para uma nova URL.
    • 400 Bad Request: A requisição possui sintaxe inválida ou não pôde ser processada pelo servidor.
    • 403 Forbidden: O cliente não possui permissão de acesso ao recurso solicitado.
    • 404 Not Found: O servidor não encontrou o recurso associado à URL informada.
    • 500 Internal Server Error: O servidor encontrou um erro interno genérico ao tentar processar a solicitação.
