GIT

O git é uma ferramente de controle de versão distribuido

Comandos do Git

  • git init: inicializa um repositório git
  • git status: mostra o status
  • git add: adiciona um arquivo no stage
  • git commit -m "": cria um commit no seu repositorio local
  • git log: exibe os commits locais da branch atual
  • git switch branch: muda de branch
  • git switch -c: cria nova branch
  • git diff: diferencia os commits e exibe a diferença
