O que é uma regra CSS?

Uma regra CSS é uma instrução que diz ao navegador como um elemento HTML deve ser exibido. Ela é formada por um seletor, que indica qual elemento será estilizado, e por um bloco de declarações entre chaves. Cada declaração tem uma propriedade e um valor, separados por dois pontos e terminados com ponto e vírgula.

Exemplo prático

h2 {
    color: darkblue;
}

Seletor: h2 | Propriedade: color | Valor: darkblue

Essa regra deixa todos os títulos h2 da página na cor azul escuro (como o título "Exemplo prático" acima).
