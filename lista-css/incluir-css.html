Como incluir CSS em um documento HTML?

Existem três formas principais de incluir CSS:

1. CSS inline

O estilo é escrito direto no elemento, usando o atributo style. Afeta só aquele elemento.

2. CSS interno

O CSS fica dentro da tag style, no head do próprio documento. Vale para a página inteira.

3. CSS externo

O CSS fica em um arquivo separado (.css) e é ligado ao HTML com a tag link, no head. É a forma mais indicada, porque o mesmo arquivo pode ser usado em várias páginas.
